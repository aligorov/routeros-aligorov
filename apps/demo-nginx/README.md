# demo-nginx

Минимальное приложение для проверки собственного app-store: официальный
образ `nginx:1.27-alpine` (multi-arch, включая arm64), один порт.

## Проверка

1. Установить `demo-nginx` из App Store на роутере.
2. Открыть `http://<ip-роутера>:8080` (или кнопка в Winbox — метка `web`).
3. Должна открыться страница «Welcome to nginx!».

Если открылась — стор, Pull образов и сеть контейнеров работают.
После проверки приложение можно удалить; из стора — убрать папку
`apps/demo-nginx/` и пересобрать `store.yaml`.
