Синхронизация профилей с сервером AWG

Ротация туннеля (смена порта, ключей, параметров обфускации и профиля маскировки QUIC/STUN/DNS) выполняется на сервере AWG. Роутер по постоянному токену и порту API 8443 регулярно проверяет статус сервера через HTTP (ETag/304) и автоматически подхватывает новые параметры сервера без разрыва связи.
